24 test calls

I didn't want to judge the prompt by vibes, so every version was run against the same 24 calls before I changed anything else.

SonicThe deployed agent: same prompt and model as the live chat.
The callerClaude plays each caller from a short brief (a lost rider, a KYC scammer, Amma, a fake "brother"), pushing like a real one would.
The judgeA separate Claude call grades each transcript against written must / must-not rules, plus style (short turns, one question, language match).
What the failures taught me
  • The model got the 10 pm handover rule wrong, so the app now passes the current rule in as a fact.
  • Strict "name the restaurant" checks turned real riders away. Now it's app match + any one detail they already know.
  • One scam call got a markdown essay back. A small output guard now strips formatting and caps length for speech.
  • The model copied a line from an example call, so examples are now clearly marked as separate calls.
  • The same prompt scored 18 and 22 on different runs. One run is never the verdict: I read the transcripts and the trend.
  • An independent audit found my suite was blind: the simulated riders always cooperated, so a caller who never names anything could get the address. The app now blocks address words to unverified callers in code, and new calls D8 to D10 test it.
  • The model sometimes spoke its own reasoning ("analysis..."). The app now speaks only the final message and retries if a reply isn't speakable.
